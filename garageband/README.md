# /garageband

macOS AppleScript / Accessibility bridge. Empty in Phase 1.

**Official vs community:** Community. GarageBand has **no official public editing API**. Apple Audio Units are for hosts/plug-ins, not `.band` documents. Wrapper path: `garageband-llm-bridge` (`renderPreview` + menus).

**Phase 0 limits:** Brittle, macOS-only, UI-state dependent. Mark every call unofficial. No connectors in this phase.
